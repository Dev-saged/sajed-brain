# فيديو كلام ساجد ← ريل بهويته

> **قبل أي شيء:** طبّق "قواعد فيديو الكلام" في `../README.md` (نص حرفي، كل لغة بخطها، كابشن أسفل قوي، صوت طبيعي، موشن من دلالات الكلام، لا مقدمة مبرمج). الأداة الحالية لا تحقق كل ذلك بعد — راجع "المطلوب تطويره" أدناه.

حين يرسل ساجد فيديو يتكلم أو يشرح فيه: يُفرَّغ صوته لنص حرفي بكل لغة بخطها، يُقصّ الصمت فقط، ويُبنى ريل: عنوان افتتاحي من المحتوى ← كلامه بكابشن قوي أسفل الشاشة وأجواء متحركة من معنى الكلام ← الخاتمة.

## المسار (أرخص بالتوكنز)
1. `python3 video-identity/talk/talk.py transcribe my.mp4 work/`
   - ينظّف الصوت ويفرّغه محلياً (faster-whisper، `large-v3-turbo` افتراضياً، `--model small` للسرعة).
   - يخرج `work/transcript.txt` (سطر لكل جملة مع زمنها) — **هذا الملف الوحيد الذي يُقرأ**؛ `words.json` لا يُفتح.
2. اقرأ النص، افهم الفكرة، واكتب `talk.json` على نمط `talk.example.json`:
   - `title`: عنوان افتتاحي من المحتوى نفسه `{text, sub, seconds}` (≤7 كلمات).
   - `fixes`: تصحيح أخطاء السمع فقط (يظهر الصحيح في الكابشن).
   - `emphasis`: كلمات تأخذ خلفية نحاسية.
   - `pops`: بطاقة كبيرة وسط الشاشة عند زمن من المصدر (`at` بالثواني)، تدعم `[رقم]` و`{نحاسي}`.
   - `zooms`: فترات دفعة زوم 12% (زمن المصدر).
   - `pop_y`: موضع البطاقة العمودي (مثل `"60%"`) حتى لا تغطي الوجه في فيديو السيلفي.
   - `keep`: `null` = قصّ تلقائي للصمت >0.6ث فقط (موصى به).
3. `python3 video-identity/talk/talk.py render talk.json out.mp4 --preview` ← صورة كابشن للمراجعة، ثم بدون `--preview` للفيديو.
   - يُؤرشف تلقائياً في `../library/` (talk.json + transcript.txt + مصغّرة؛ الفيديو الأصلي لا يُخزَّن).

## ما يحدث في الرندر
- قصّ المقاطع ودمجها، تحويل لعمودي 1080×1920 (تعبئة وقص من المنتصف)، زوم في اللحظات المحددة.
- صوت: إزالة همهمة + ضوضاء + توحيد الارتفاع لـ -14 LUFS (معيار الريلز).
- كابشن: دفعات ≤3 كلمات، الكلمة الحالية نحاسية، فوق المنطقة الآمنة، على خلفية فيروزية شفافة.
- المقدمة والخاتمة من `../templates/video.html` بنفس الهوية.

## المتطلبات
`pip install --break-system-packages faster-whisper` + playwright + ffmpeg. أول تشغيل ينزّل نموذج Whisper.

## ما تفرضه الأداة الآن (قواعد ساجد 2026-11-18)
- **التفريغ:** يحتفظ بالإنجليزي بحروفه (initial prompt مختلط) + قاموس `rules/arabizi.json` يعيد الكلمات الإنجليزية المكتوبة عربياً لحروفها. أضف للقاموس كل كلمة جديدة تظهر.
- **النص حرفي:** القص التلقائي للصمت فقط. أي `keep` يحذف كلمة منطوقة يُرفض إلا بـ`approved_cuts` (موافقة ساجد). لا حذف للحشو.
- **`fixes` لأخطاء السمع فقط:** يُرفض المفتاح غير الموجود في التفريغ، وتعريب الإنجليزي (`ڤ` أو Latin ← عربي).
- **لا مقدمة terminal:** `hook` يُرفض؛ الافتتاحية `title` من المحتوى فوق أول ثانيتين مع استمرار الكابشن.
- **الصوت طبيعي:** رفع مستوى فقط حتى قمة -1.5dB، بلا تخفيف ضوضاء.
- **الكابشن:** أسفل الشاشة، حدّ وظل قويان بلا صندوق، الإنجليزي LTR داخل السطر العربي.
- **الأجواء:** `fx` تلقائية من معنى الكلام (مطر، شاي، نار، دعاء ← rain/steam/fire/sparkle) أو يدوية: `[{"type":"rain","from":0,"to":20}]` بزمن المصدر. تظليل سينمائي + درجة لونية خفيفة + زوم متناوب عند كل قطع.
- **فحص قبل التسليم:** أي بطاقة أو كابشن خارج الشاشة أو بطاقة فوق الكابشن ← الرندر يفشل ولا يُسلَّم فيديو معيب.

## عناصر الموشن (من خلاصة المراجع — `../references/motion/SYNTHESIS.md`)
كل الأزمنة بزمن المصدر (كما في transcript.txt). المثال الكامل: `talk.example.json`.
| الحقل | التقنية | ملاحظة |
|---|---|---|
| `grade` | mood-grade: `teal` (افتراضي) / `wine` / `amber` / `natural` | يلوّن الفيديو وخلفيات البطاقات |
| `keywords` + `kashida` | keyword-glow + kashida-type: كلمة الذروة ضخمة متوهجة نحاسية في سطر مستقل، ممطوطة بالتطويل | الإنجليزي يبقى في سطره بترتيبه |
| `cards` | typo-card / semantic-broll: `typo` نص ضخم، `icon` أيقونة Phosphor duotone متحركة بأشعة وهالة، `image` صورة بحركة Ken Burns | الأيقونات المتاحة في `icons/` (56، رخصة MIT) |
| `frames` | frame-in-frame: الفيديو يصغر لنافذة مدورة فوق خلفية مصممة مع رقم وعنوان | للخطوات والشرح |
| `ui` | floating-ui-cards: بطاقة زجاجية بقائمة تدخل عناصرها تباعاً | |
| `phones` | phone-in-hand: جوال يعرض لقطة شاشة حقيقية | لتطبيقات ساجد |
| `behind` | text-behind-subject: نص ضخم خلف ساجد (فصل الشخص محلياً بـMediaPipe) | يصغر تلقائياً ليتسع |
| `spotlight` | spotlight-ring: حلقة نحاسية تتبع الوجه + عنوان صغير | كشف الوجه محلياً |
| `music` | موسيقى تنخفض تلقائياً حين يتكلم (sidechain) | ملف من مكتبة ساجد |
| `sfx` | مؤثرات صوتية مولّدة رقمياً: whoosh/pop/impact/shimmer مع كل عنصر | `false` لإيقافها |

- **النماذج:** `models/` (selfie_segmenter + face_detector، Apache-2.0) — تعمل بلا إنترنت.
- **المحرّك:** كل إطار يُركَّب في `talk.html` فوق إطار الفيديو الحقيقي (`compose.composite`)، ثم الصوت (`compose.mix_audio`). دقيقة فيديو ≈ 6 دقائق رندر.
