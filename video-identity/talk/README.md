# فيديو كلام ساجد ← ريل بهويته

حين يرسل ساجد فيديو يتكلم أو يشرح فيه: يُفرَّغ صوته لنص، يُقصّ الصمت والحشو، ويُبنى ريل بالهوية: مقدمة (hook) ← كلامه مع كابشن كلمة بكلمة ومؤثرات ← الخاتمة.

## المسار (أرخص بالتوكنز)
1. `python3 video-identity/talk/talk.py transcribe my.mp4 work/`
   - ينظّف الصوت ويفرّغه محلياً (faster-whisper، `large-v3-turbo` افتراضياً، `--model small` للسرعة).
   - يخرج `work/transcript.txt` (سطر لكل جملة مع زمنها) — **هذا الملف الوحيد الذي يُقرأ**؛ `words.json` لا يُفتح.
2. اقرأ النص، افهم الفكرة، واكتب `talk.json` على نمط `talk.example.json`:
   - `hook`: خطّاف من الكلام نفسه (≤7 كلمات، رقم أو سؤال) — من `../ideas/playbook.md`.
   - `fixes`: تصحيح كلمات التفريغ الخاطئة (يظهر الصحيح في الكابشن).
   - `emphasis`: كلمات تأخذ خلفية نحاسية.
   - `pops`: بطاقة كبيرة وسط الشاشة عند زمن من المصدر (`at` بالثواني)، تدعم `[رقم]` و`{نحاسي}`.
   - `zooms`: فترات دفعة زوم 12% (زمن المصدر).
   - `keep`: `null` = قصّ تلقائي للصمت >0.6ث والحشو (يعني، اممم…)، أو قائمة `[[بداية، نهاية]]`.
3. `python3 video-identity/talk/talk.py render talk.json out.mp4 --preview` ← صورة كابشن للمراجعة، ثم بدون `--preview` للفيديو.
   - يُؤرشف تلقائياً في `../library/` (talk.json + transcript.txt + مصغّرة؛ الفيديو الأصلي لا يُخزَّن).

## ما يحدث في الرندر
- قصّ المقاطع ودمجها، تحويل لعمودي 1080×1920 (تعبئة وقص من المنتصف)، زوم في اللحظات المحددة.
- صوت: إزالة همهمة + ضوضاء + توحيد الارتفاع لـ -14 LUFS (معيار الريلز).
- كابشن: دفعات ≤3 كلمات، الكلمة الحالية نحاسية، فوق المنطقة الآمنة، على خلفية فيروزية شفافة.
- المقدمة والخاتمة من `../templates/video.html` بنفس الهوية.

## المتطلبات
`pip install --break-system-packages faster-whisper` + playwright + ffmpeg. أول تشغيل ينزّل نموذج Whisper.
