# قوالب فيديو ساجد — جاهزة للتركيب

فيديو كامل 9:16 (1080×1920، 30fps، ~13ث) من ملف محتوى واحد. الهوية تُقرأ تلقائياً من `../tokens.json` و`../icons/platforms.json` — لا تكتب ألواناً أو خطوطاً في أي مكان آخر.

## الاستخدام (أرخص مسار بالتوكنز)
1. انسخ `content.example.json` وعدّل الحقول فقط (~12 سطراً).
2. معاينة سريعة (3 صور): `python3 video-identity/templates/render.py my.json out.png --preview`
3. الفيديو: `python3 video-identity/templates/render.py my.json out.mp4`

لا تقرأ `video.html` ولا `render.py` إلا لتعديل القالب نفسه.

## حقول المحتوى
| الحقل | المعنى |
|---|---|
| `command` | يظهر في سطر الـterminal بعد `~/gaza/dev-saged $` |
| `headline` | عنوان الـhook، يُكتب حرفاً حرفاً. `\n` سطر جديد، `[نص]` بلون الأرقام، `{نص}` باللون النحاسي |
| `sub` | سطر تحت العنوان |
| `demo.screenshot` | مسار لقطة شاشة التطبيق الحقيقية (نسبي لملف المحتوى) أو `null` لهيكل مؤقت |
| `demo.before/after` | `label` و`value`، و`after.ratio` (0–1) طول شريط "بعد" |
| `demo.headline` | عنوان شاشة العرض، `{نص}` يأخذ تظليلاً نحاسياً |
| `demo.caption` | الكبسولة السفلية |
| `durations` | ثواني كل مشهد (افتراضي 3.5 / 5 / 4.5) |

## المشاهد
1. **hook** — خلفية فيروزية داكنة، شبكة متحركة ووهج نحاسي، صورة ساجد + "مطوّر من غزة"، سطر terminal، عنوان يُكتب مع مؤشر ▍.
2. **demo** — خلفية حجرية، جوال ينزلق بلقطة التطبيق، بطاقة قبل/بعد مع شريط يتقلّص، عنوان، كبسولة.
3. **outro** — الصورة بحلقة نحاسية، الاسم، "مطوّر تطبيقات · من غزة"، 6 بلاطات حسابات تدخل تباعاً.

## قواعد ثابتة
- المنطقة الآمنة للريلز: لا نص في أسفل 380px، ولا في يمين 160px من النصف السفلي.
- الخطوط محلية في `fonts/` (OFL) — الرندر يعمل بلا إنترنت.
- مشهد جديد = قسم `<section>` + دالة في `scenes` داخل `video.html`، بنفس الألوان والحركة (easeOutCubic / easeOutBack).
- المتطلبات: Python 3 + playwright + ffmpeg.
